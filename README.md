# Database 
## event_sources

Хранит источники поступления событий безопасности.

Примеры:
* nginx
* sshd
* fail2ban

Используется для определения происхождения события и построения аналитики по источникам.

---

## event_types

Справочник типов событий безопасности.

Примеры:
* auth_failed
* brute_force
* malware_detected
* port_scan

Позволяет нормализовать события независимо от их исходного формата.

---

## events

Основная таблица системы мониторинга.

Содержит:
* информацию о событии
* уровень критичности
* IP-адреса
* hostname
* время возникновения
* исходные данные события
* нормализованные данные

Таблица используется как основное event storage приложения.

---

## event_analysis

Хранит результаты анализа событий.

Содержит:
* threat score
* уровень угрозы
* метод обнаружения
* вывод анализа
* рекомендации
